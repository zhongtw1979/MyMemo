# MyMemo

**录音笔接入 Mac，自动保存录音，并在本机生成中文文字稿。**

MyMemo is a native macOS app for importing recordings from selected devices, detecting new or changed files, and transcribing audio on the Mac.

作者：**钟天炜** · 联系方式：**微信 zhongtw**

当前版本为 **0.3.0 开发者预览版**。面向 Apple Silicon（M 系列）Mac，最低要求 **macOS 26**。请先阅读下方的运行要求和已知限制。

[下载开发者预览包](https://github.com/zhongtw1979/MyMemo/releases) · [查看构建与测试](https://github.com/zhongtw1979/MyMemo/actions/workflows/macos.yml)

## 能做什么

- 三步引导：选择设备、选择保存位置、确认是否生成文字。
- 设备接入后自动识别，也支持手动导入本地录音文件夹。
- 检查实际媒体轨道，只导入纯音频，跳过视频和无法确认的文件。
- 自动校验、按内容去重，原设备中的文件保留。
- 再次接入时快速检查新增或变化的文件，避免重复复制和转写。
- 使用 Apple SpeechAnalyzer 在本机转写，输出 TXT 和 Markdown。
- 查看录音、搜索、打开文字稿、暂停处理和重试失败任务。
- 清单支持列标题排序及排序菜单，可按名称、导入时间、大小、设备和状态排序。
- 搜索文件名、设备和文字稿正文，支持中文短词；正文索引保存在本机，首次按需建立。
- 文字稿采用后台读取、限量缓存和 Mac 原生文本控件；支持关键词高亮、刷新、复制全文和 Markdown 回退。
- 菜单栏后台运行，登录启动由用户主动开启。

## 开始使用

1. 打开应用，选择已连接的录音设备。设备需要像 U 盘一样出现在 Finder 中；也可以选择电脑上的录音文件夹。
2. 选择保存位置，默认推荐“音乐 / MyMemo 录音”。
3. 选择生成文字或仅保存录音。中文识别未就绪时，点击“准备中文识别”，然后开始整理。

引导完成前不会自动导入设备文件。首次准备语言模型需要联网，模型就绪后可离线识别。识别结果属于机器转写，专有名词、数字和重要内容应结合原始录音核对。

## 安装和构建

需要安装 Xcode 26 或更高版本，提供 Swift 6.2 及以上工具链，并选择支持 macOS 26 的 SDK。普通用户运行应用不需要安装 Xcode、Codex 或 Python。

```bash
git clone https://github.com/zhongtw1979/MyMemo.git
cd MyMemo
bash scripts/swift.sh test
bash scripts/build-app.sh
```

构建产物位于 `dist/`。将完整 `.app` 放入“应用程序”文件夹后打开。

此前使用原工具版、录音库位于 `~/Library/Application Support/MyMemo/` 的用户，可以构建兼容升级包：

```bash
bash scripts/build-app.sh --classic
```

该包继续使用工具版原来的录音记录和文件位置。请退出旧 MyMemo 后再打开升级包；旧 App 可以保留。兼容包第一次打开已有库时默认暂停自动整理，方便核对记录。普通引导版继续使用独立的 `MyMemoGuided` 数据目录。

构建脚本会将源码复制到系统临时目录中编译，避免 iCloud 同步目录中的文件时间变化干扰构建。构建缓存位置记录在本地 `.build-location`，不会提交到仓库。

当前公开预览包使用临时签名，**尚未完成 Developer ID 签名和苹果公证**，下载后可能被系统拦截。源代码开源不等于获得苹果公证。正式客户分发应完成签名、公证，并在未安装开发环境的兼容 Mac 上验证。

## 快速增量检查

首次扫描建立记录。以后通过设备标识、设备内相对路径、文件大小、修改时间和分段内容指纹判断是否发生变化。

- 未变化的录音和已确认的视频，走快速检查。
- 新增或检测到变化的文件，进入完整媒体检查和内容校验。
- 本机副本缺失或被改动时，重新检查并补拷。
- 已完成的文字稿不会因为再次插入设备而重新生成。
- 设备不提供 UUID 时，以源目录定位；位置变化可能需要重新检查一次，内容去重仍然有效。

快速模式仍需遍历目录，并读取少量内容。每个较大文件最多读取首、中、尾共 192 KiB，本机副本也进行对应检查。若大小和时间均保持不变，且修改完全落在未采样区域，快速模式可能漏过；设置中的“完整检查录音来源”会重新读取完整录音进行核对。新录音复制始终执行完整 SHA-256 校验。

## 数据与隐私

正常运行的数据位于：

```text
~/Library/Application Support/MyMemoGuided/
  config.json       # 设备和转写设置
  experience.json   # 引导状态与暂停状态
  library.json      # 导入历史、转写状态和增量索引
  browser.json      # 清单排序偏好
  transcript-search.sqlite3  # 本机正文搜索缓存
```

录音和文字稿保存在用户选择的文件夹中。复制 App 不会自动迁移配置、历史或模型。程序不删除录音设备上的源文件；记录损坏时会停止处理，避免静默丢失历史。

正文搜索缓存包含文字稿内容，只存储在相应的本机数据目录。它可以重新建立，不修改原文字稿。首次搜索会显示索引进度；外部编辑后可使用“刷新正文索引”。当前预览单篇最多载入 2 MiB，超出时明确提示打开原文件；正文索引单篇上限为 32 MiB，无法读取或超限的文件会计入未索引数量。

默认使用本机识别。高级设置保留火山引擎外部脚本适配接口，默认未启用，脚本不随本仓库提供。启用时需要用户明确允许上传录音，并自行配置服务与凭据，参见 [外部转写接口](docs/external-transcription.md)。

## 可选工具与限制

- FFmpeg / FFprobe：可选，用于额外音频格式和更完整的媒体轨道检查。没有安装时使用系统媒体接口，无法确认的文件会跳过。应用包不包含 FFmpeg。
- Python 与云端脚本：仅外部云端适配需要，本机转写不依赖它们。
- Intel Mac、macOS 26 之前的系统、MTP 和厂商专用连接协议目前不支持。
- 真正进入系统睡眠后，处理也会停止；合盖不等于能够继续运行。
- 关闭窗口后仍在菜单栏运行；退出应用会停止处理。
- 完整 GUI 回归、更多真实录音笔、长时间大量文件和跨机器兼容性验证仍需继续完善。

## 项目结构

```text
Sources/MyMemoCore/          媒体筛选、导入、去重、转写与持久化
Sources/MyMemoExperience/    引导校验、录音查询和文字稿读取/索引
Sources/MyMemoGuided/        SwiftUI 界面与设备监听
Tests/                      核心与引导流程测试
Resources/                  应用信息与图标
scripts/                    构建与测试辅助脚本
```

测试样例由程序生成，不包含用户真实录音。46 项 macOS 自动测试覆盖媒体筛选、复制完整性、去重、增量扫描、设备标识、断点恢复、引导校验，以及排序、正文索引和文字稿缓存。合成数据界面验证见 [0.3.0 验证记录](docs/recording-browser-verification.md)。语音模型下载及真实云端请求不作为单元测试的一部分。
