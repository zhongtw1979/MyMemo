# 0.3.0 验证记录

验证日期：2026-09-08。界面操作仅使用独立临时目录中的合成测试数据，自动导入和自动转写均关闭。

## 自动化验证

46 项测试覆盖现有导入、媒体筛选、增量处理，以及新增的自然名称排序、时间/大小/设备排序、状态筛选、正文索引持久化及更新、中文短词、查询参数隔离、TXT/Markdown 回退、长文 UTF-8 截断、缓存复用、并发读取和快速切换防串稿。

合成性能样本为 5,000 条记录及 220,000 字文字稿。一次本机测试测得：元数据搜索及排序约 19 ms、首次读取约 3.5 ms、缓存读取低于 1 ms。这些数字仅表示后端处理时间，不表示窗口渲染时间，也不保证其他电脑上的耗时。

## 界面验证

使用 300 条合成录音，在经典版升级包中实际操作：

- 无选择时清单铺满内容区域；选中录音显示右侧文字稿；关闭预览恢复完整清单。
- 文件名升序呈现 0、1、2 等自然次序；切换降序后从 299 开始。
- 搜索“预算”找到仅在正文包含该词的第 17 条录音，结果为 1 条。
- 288,018 字合成长稿能够显示和滚动，关键词高亮正常。
- ⌘F 聚焦搜索，清空关键词后恢复 300 条清单。
- 切换到其他录音后，文字稿标题、正文和字数一致，长稿内容未覆盖新选择。

验证中发现分栏容器未占满可用高度，已修正并重新打开应用核对。界面操作未调用真实转写服务；当前版本未完成 Developer ID 签名或 Apple 公证。

两个 ZIP 均完成解压后的签名完整性校验。iCloud 可能给工作目录中的 App 副本附加 Finder 信息，因此以 ZIP 解压后的校验结果为准；正式分发仍需签名及公证。
