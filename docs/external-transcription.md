# 外部转写接口

本机 Apple 转写无需外部脚本。高级设置中的火山引擎选项为外部 Python 程序适配接口，脚本路径默认留空。

启用该选项需要：Python 运行环境、兼容脚本、该服务的有效凭据，以及用户在界面中明确允许上传录音。调用可能产生服务费用。

## 调用约定

应用通过参数数组启动程序，不拼接 Shell 命令：

```text
PYTHON SCRIPT transcribe SOURCE --work-dir TEMP_DIRECTORY
```

`SOURCE` 是已经保存并校验的本机录音副本。脚本成功退出时，在临时目录写入 UTF-8 的 `raw-transcript.txt`。非零退出状态或空结果会标记失败，用户可选择重试。

现有适配约定由外部脚本读取 `~/.config/volc/agent-plan.env`，应用不会读取密钥内容，也不会将它写入配置或日志。不要将凭据文件放进仓库。具体 API 调用和认证由使用者提供的脚本实现。

临时工作目录会在处理结束后清理，原始录音保留。子进程标准输出与错误输出不进入应用日志。云端请求意外中断后等待用户手动重试，避免重启时重复计费。
